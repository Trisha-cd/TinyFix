TinyFix

TinyFix is a beginner-friendly Python project that helps users take small, manageable steps when they feel stuck.

Features

- Suggests actions based on available time.
- Helps users work through common obstacles.
- Collects user feedback.
- Displays a simple feedback report.

Technologies Used

- Python

How to Run

Run the following command in a terminal:

"python tinyfix.py"

Purpose

This project was created to practise Python programming, conditional statements, dictionaries, file handling, and basic data analysis.
